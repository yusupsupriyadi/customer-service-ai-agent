# Tutorial page for students

## Summary

Added `tutorial.html`, a step-by-step guide (Indonesian, for grade 11 vocational students) that explains how the customer service agent is built, with code excerpts taken from the real source.

## Changes

- `tutorial.html`: table of contents, setup and Netra API key steps, six build steps, test scenario, troubleshooting list, security notes, exercises, copy buttons on code blocks.
- `index.html`: header link "Baca tutorial" to `tutorial.html`.
- `README.md`: listed `tutorial.html` in the file table.

## Decisions

- Netra facts (key creation, status codes 401/402/404/429, reasoning tokens counted as output, `enabled: true` = effort high) come from https://netra.sh/docs/ pages, linked in the tutorial.
- Same visual language as the app (stone + emerald accent), dials ENERGY 1 / RHYTHM 1 / MOTION 1.

## Verification

- Node script: every in-page anchor and copy target exists, no duplicate ids, 8 app.js excerpts match the source exactly, no unescaped `<` in code blocks, inline script passes `node --check`.
- No em or en dashes in project files.

- Expected agent answers in the test scenario were not verified with a real API key.
